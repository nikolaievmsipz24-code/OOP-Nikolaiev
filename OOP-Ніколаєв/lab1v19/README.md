## Контрольні запитання

### 1. Що таке клас та об’єкт? Яка між ними різниця?
* **Клас** — це користувацький тип даних, своєрідний «кресленик» або шаблон, який визначає структуру майбутніх об'єктів (їхні поля, властивості та методи).
* **Об’єкт** — це конкретний екземпляр класу, який створюється в пам'яті комп'ютера на основі цього шаблону.
* **Різниця:** Клас є абстрактним описом, а об'єкт — це реальна сутність із конкретними значеннями даних.

### 2. Для чого використовуються конструктори? Чи може клас існувати без них?
* **Конструктор** використовується для ініціалізації об'єкта під час його створення (присвоєння початкових значень полям).
* **Так, клас може існувати без явища написаного конструктора:** у такому разі компілятор автоматично створює прихований конструктор за замовчуванням, який заповнює поля стандартними пустими значеннями.

### 3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?
* **Приватне поле** (`private`) — це змінна всередині класу, яка прихована від зовнішнього коду для безпеки даних.
* **Публічна властивість** (`public` з блоками `get` / `set`) — це контрольований інтерфейс, який дозволяє безпечно зчитувати або змінювати значення приватного поля.
* **Інкапсуляція** потрібна для приховування внутрішньої реалізації об'єкта, захисту даних від некоректного змінення та забезпечення безпеки коду.
