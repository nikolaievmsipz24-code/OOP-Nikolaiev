**Проєкт:** `lab11v19` | **Варіант 19:** Компанії та їхні відділи з працівниками

## 1. Опис сутностей і тестових даних
Реалізовано три класи сутностей у просторі імен `lab11v19.Models`:
- `Employee` (`Id`, `Name`, `Salary`) — працівник із заробітною платою.
- `Department` (`Id`, `Name`, `List<Employee> Employees`) — відділ зі списком працівників.
- `Company` (`Id`, `Name`, `List<Department> Departments`) — компанія зі списком відділів.

Тестові дані (`SeedData()`) містять **3 компанії**, **9 відділів** і **21 працівника** (сумарно 33 об'єкти у вкладеній ієрархії).

## 2. Виконання запитів LINQ у `Program.cs`
- **`SelectMany`:** `companies.SelectMany(c => c.Departments).SelectMany(d => d.Employees)` об'єднує всі підколекції в один плоский список з 21 працівника.
- **Пагінація (`Skip` / `Take`):** для виводу відділів по **3 елементи на сторінку** для сторінок 1, 2 і 3 використовується вираз `Skip((page - 1) * 3).Take(3)`.
- **Метод розширення (`AverageDepartmentSalary()`):** у статичному класі `DepartmentExtensions` (`lab11v19.Extensions`) реалізовано метод `this Department department`, який безпечно обробляє порожній список (`0m`) і обчислює середню зарплату через `Employees.Average(e => e.Salary)`.

## 3. Короткий висновок
У ході лабораторної роботи `lab11v19` відпрацьовано згладжування вкладених колекцій через `SelectMany`, посторінкову вибірку даних за допомогою `Skip` і `Take` та створення власних методів розширення для доменних сутностей.

## 4. Відповіді на контрольні питання

### 1. Для чого використовується оператор `SelectMany`? Наведіть приклад, що демонструє його відмінність від `Select`.
`SelectMany` проєктує кожен елемент послідовності у підколекцію та згладжує всі підколекції в одну загальну послідовність.
- `departments.Select(d => d.Employees)` повертає `IEnumerable<List<Employee>>` (колекцію списків).
- `departments.SelectMany(d => d.Employees)` повертає `IEnumerable<Employee>` (один плоский перелік усіх працівників).

### 2. Як реалізувати пагінацію даних за допомогою LINQ? Які методи для цього використовуються?
Пагінація реалізується через **`Skip(count)`** (пропускає `count` попередніх елементів) та **`Take(count)`** (відбирає наступні `count` елементів):
```csharp
var pageItems = items
    .Skip((pageNumber - 1) * pageSize)
    .Take(pageSize);
3. Поясніть концепцію методів розширення. Як вони інтегруються з LINQ?
Методи розширення — це статичні методи у статичному класі з модифікатором this перед першим параметром, які викликаються як методи екземпляра без зміни вихідного класу. Стандартний LINQ (System.Linq.Enumerable) побудований на методах розширення для IEnumerable<T>, тому власні методи розширення органічно вбудовуються в ланцюжки LINQ-запитів.
